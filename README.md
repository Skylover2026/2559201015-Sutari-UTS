# ASTÉRA – Fashion Website

## 1. Deskripsi Website
ASTÉRA merupakan sebuah website fashion yang dirancang sebagai media informasi dan promosi produk fashion dengan konsep elegan, modern, dan mewah. Website ini mengusung perpaduan warna cokelat vintage, beige, dan cream untuk menciptakan kesan klasik serta eksklusif.

ASTÉRA memiliki slogan **"Wear What Makes You Feel Confident & Uniquely."** yang berarti setiap orang dapat mengekspresikan gaya dan identitas dirinya melalui fashion.

## 2. Tujuan Pembuatan
Website ASTÉRA dibuat untuk:
- Memperkenalkan brand fashion ASTÉRA.
- Menampilkan informasi mengenai brand.
- Menyediakan katalog produk fashion beserta harga.
- Memudahkan pengunjung mendapatkan informasi kontak.
- Memberikan pengalaman menjelajahi website yang menarik dan mudah digunakan.

## 3. Fitur Website
Website ASTÉRA memiliki beberapa halaman utama:

1. **Beranda**  
   Menampilkan halaman utama dengan banner koleksi fashion dan tombol Explore Now.

2. **Tentang**  
   Berisi informasi mengenai profil, visi, misi, dan identitas brand ASTÉRA.

3. **Katalog**  
   Menampilkan berbagai produk fashion beserta deskripsi dan harga. Dilengkapi fitur pencarian dan filter kategori.

4. **Kontak**  
   Menyediakan informasi kontak, lokasi, serta formulir pesan.

## 4. Teknologi yang Digunakan
- **HTML5** – Membuat struktur halaman website.
- **CSS3** – Mengatur tampilan, warna, layout, dan responsivitas website.
- **JavaScript** – Menambahkan interaksi seperti pencarian produk, filter kategori, navigasi, dan validasi formulir.

## 5. Konsep Desain
Website ASTÉRA menggunakan konsep *Elegant Vintage Fashion* dengan karakteristik:
- Warna dominan cokelat, beige, dan cream.
- Tipografi yang elegan dan modern.
- Tampilan minimalis dan terstruktur.
- Gambar bertema fashion sebagai elemen visual.
- Desain responsif untuk berbagai ukuran layar.

## 6. Cara Menjalankan Website
1. Download atau ekstrak folder project ASTÉRA.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan seluruh folder dan file pendukung berada pada lokasi yang sesuai.
4. Buka file `index.html` menggunakan browser.
5. Website ASTÉRA siap digunakan.

## 7. Penutup
Dengan dibuatnya website ASTÉRA, diharapkan brand ini dapat memiliki media digital yang mampu memperkenalkan identitas, menampilkan produk, serta memberikan informasi kepada pengunjung secara menarik dan informatif.
